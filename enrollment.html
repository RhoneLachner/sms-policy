SMS Enrollment and Consent

Refurbished Product Availability Alerts, operated by Sarah Lachner. Effective September 19, 2026.

What the application does

Refurbished Product Availability Alerts is a scheduled software application. It reads Apple's public Certified Refurbished online store every 30 minutes, compares each listing against a saved product specification, and sends an automated SMS notification when a listing matching that specification appears. Messages are generated by the software. No message is composed by a person.

How a mobile number is enrolled

A mobile number receives alerts only after it is entered into the application's configuration during setup. Before entering a number, the person performing the setup must confirm the consent statement below. The setup documentation displays this statement at the step where the number is entered, and the number is stored as a private configuration secret.

Consent statement shown at enrollment

I agree to receive SMS alerts from Sarah Lachner Refurbished Product Availability Alerts at this number. Message frequency varies and is expected to be fewer than 5 messages per month. Message and data rates may apply. Reply STOP to opt out. Reply HELP for help. See the Privacy Policy and Terms and Conditions.

Numbers are never obtained any other way

No mobile numbers are purchased, rented, imported from a list, or collected from any third party. A number that was not entered through the setup step described above cannot receive messages from this application.

Stopping messages

Reply STOP to any message to stop receiving messages. Reply HELP for help. A number can also be removed from the application's configuration, which stops all messages to it immediately.
