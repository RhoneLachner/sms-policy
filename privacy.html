Privacy Policy

Refurbished Product Availability Alerts. Effective September 19, 2026.

Who operates this service

This service is operated by Sarah Lachner, a sole proprietor. Contact: fernandclay@gmail.com.

What this service is

A personal notification tool that sends an SMS text message to a single recipient, the operator, when a specified Apple Certified Refurbished product configuration becomes available in Apple's online refurbished store.

Information collected

One mobile telephone number, belonging to the operator, entered by the operator into the application's own configuration. No other personal information is collected. No information is collected from any other person, and no other person is able to subscribe to these messages.

How mobile information is used and shared

The mobile telephone number is used for one purpose only: delivering the text message alerts described above.

Mobile telephone numbers are not sold, rented, or disclosed to any third party for any purpose. No mobile information is shared with third parties or affiliates for marketing or promotional purposes. The number is disclosed only to the messaging carrier as required to deliver the message.

Message frequency

Message frequency varies. Messages are sent only when a matching product listing appears, which is expected to be fewer than 5 messages per month.

Rates

Message and data rates may apply.

Stopping messages

Reply STOP to any message to stop receiving messages. Reply HELP for help.

Data retention

The application stores only the product identifiers it has already sent an alert for, so that the same listing does not trigger a repeated message. It does not store message content, browsing history, or any information about any person other than the operator's own telephone number.
